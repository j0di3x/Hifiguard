# Changelog

## 1.1 — 2026-10-29

- Update check: at launch and every day at 9:00 (or on wake, if the Mac slept through 9:00). It only shows a Download button and never installs anything by itself. It can be turned off.
- Open at login option.
- New look for the installer DMG.

## 1.0 — 2026-10-29

First release.

- Hi-fi Lock: keeps Bluetooth headphones in high-quality playback mode by moving the default input to another mic. Restores your previous input when you turn it off or quit.
- Status line names any app that uses the headphone mic directly.
- System-wide 10-band equalizer using Core Audio process taps, with 12 presets and a look-ahead limiter.
- Menu bar only, no Dock icon. About 0% CPU while idle.
